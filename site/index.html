Kemas

Take or pick a BEFORE photo and an AFTER photo of the same spot. This page marks what changed and tallies recognizable objects in each photo.

Everything runs in this browser tab. Photos are never uploaded; the model file is downloaded once (4.6 MB) and the page makes no other network calls. This is a counterpart to the Android app, which stays the place for the camera ghost-overlay and the home-screen widget. The result counts known objects only. It does not judge whether anything is clean.
