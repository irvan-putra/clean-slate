# Responsive widget candidate 0.3.1

Prepared source, not a signed release. The currently delivered APK has not changed.

- 1x1 minimum, both-axis resize through the launcher grid. One column shows a counter; 2-3 columns show a populated one-row summary (never a blank counter); wider or taller views retain detail.
- Widget faces have no demo label by request. Demo mode remains opt-in and clearly marked inside the app. Synthetic data stays separate from real profiles.
- Normal-font resource renders cover all 30 integer spans in a 5x6 grid. Actual Android widget-host qualification covers six widgets together, intermediate and extreme aspect ratios, resize transitions and taps. This is not exact Samsung OneUI acceptance or large-font proof.
